# 0.110.0 界面细节更新

更新于 2026-10-26。继续保留 0.108.0 气体与 0.109.0 供应器机制的未提交改动；Git 基线 main / 36f34b0。未暂存、提交、推送、创建 Release，未启动或部署游戏。

## 完成内容

- **供应器布局**：覆盖右侧不再使用的旧槽框／长罐框，统一手动输入槽、流体图标、按钮和状态文字；中英文按钮使用短标签。玩家物品、鼠标携带物和 tooltip 按正常容器绘制顺序显示。
- **模式与状态**：五模式全部显示当前标记，提供当前模式说明；左键切换下一模式，右键切换上一模式，键盘聚焦后也可操作。等待退回时显示目标模式；状态栏区分网络在线／离线、合成锁与退回中。兼容缺少新可选字段的旧菜单快照。
- **输入组**：有效范围为 -1 或 0..65535；空值、编辑中的负号和越界值不会发送。非法输入变色，确认按钮按状态启用；Enter 应用、Esc 放弃修改、Tab 切换焦点，输入时不误触背包快捷键。提示同时显示服务端当前组。隔离模式自动分组，输入框不可编辑。
- **缓冲查看**：图标、名称、数量分列；四行可见，滚轮／拖动滚动条浏览本页，分页箭头仅在缓冲视图出现并按边界禁用。空缓冲有明确提示。悬停显示来源槽、材料类型和精确数量，流体／气体标明 mB；长名称可省略，数量不会被名称挤掉。数量使用 long，支持 k/M/G/T/P/E 缩写。
- **预览包**：仍每页最多 32 行，附加类型与图标。大于 4096 字节估算大小的图标标签退回基础物品图标；极长显示文案也截短，避免填充容器把整份内部仓储塞进预览包。实际 AEKey、材料数量和完整存档保持原值。没有改变网络包字段顺序，通信协议仍为 **4**。
- **手动流体**：第三格显示类型图标，悬停显示名称、精确数量／容量及容器操作提示。只有光标上有流体容器且不在退回时启用转移按钮；成功／失败由服务端操作栏反馈。手动输入继续共享、不随缓存退回。
- **ME 总线**：流体改为原生方块图集贴图＋tint，保留纹理和动画；数量标签保持在 16px 格内，罐条计算避免乘法溢出；修复背包物品 tooltip 和自定义 tooltip 绘制顺序，标题与在线状态互相留出空间。
- **预览细节 E11**：蓝图与 JEI 共用可见／总方块状态栏及底部菜单折叠，折叠保留当前切层、循环、信息状态，隐藏按钮不会继续响应；长标题可悬停查看，信息框限制在面板内，文字区域不会选择后面的模型。
- **F3**：显示实际预览方块数和最近 64 次绘制调用的平均／峰值耗时，标明旧数据，断线清空。读数为客户端绘制调用耗时。对照旧版 PreviewStatusBar、MachineStructurePreviewPanel.handleMenuButton、ClientHandler.onDebugText 和 DebugOverlayHelper：本版没有旧专用缓冲池或异步编译器，1.20.1 也没有旧 metadata，因此不伪造缓冲池／VBO／OptiFine 编译进度与 metadata 数字。
- **影子方块**：补 CUTOUT 渲染层，透明覆盖贴图采用与供应器一致的处理。
