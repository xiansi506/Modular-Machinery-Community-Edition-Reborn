# 世界模型隐藏更新 · 0.114.0

2026-10-26。按所有者“继续下一项”补齐世界成型模型隐藏，未修改游戏实例或 Git 历史。

## 对照与实现

旧 1.12.2 源码 `client/world/BlockModelHider.java`：找不到可用自定义模型则解除隐藏；有模型时始终隐藏控制器原模型，只有开关为 true 才额外隐藏实际 foundPattern。旧代码依赖辅助隐藏模组。本版通过 Forge 自带 coremod 接入地形、流体、方块实体和邻面剔除，无新增运行库依赖；GeckoLib 仍可选。

成型且自定义模型成功渲染后隐藏原控制器模型；开启 `hide-components-when-formed`／`.hideComponentsWhenFormed(true)` 时，同时隐藏实际结构组件的方块、流体和方块实体外观。动态扩展、重叠机器、拆解、区块卸载及脚本／资源重载均更新隐藏范围；模型失败恢复普通方块显示。接入原版和 Embeddium 0.3.31 渲染路径。

服务端把已旋转的实际结构偏移写入既有控制器 NBT 的 `formedParts` 长数组，并在同机器 ID 的结构范围变化时同步。旧存档缺键时，客户端暂按运行时结构重建；不强加载区块。客户端用弱引用跟踪成功渲染的世界控制器，排除预览世界；按世界身份发布不可变位置集合供地形线程读取，共享位置按贡献并集合并，保留所有有效控制器的自定义渲染器。变化时重建相关区段及邻面。

## 边界与接手

隐藏只改显示，实际方块、碰撞、流体、端口和配方不变。隐藏由客户端 tick 与地形重建更新，可能短暂保留上一帧地形。未实机、未部署、未提交／推送；实例实查 0.110.0（协议 4），哈希与 v0.110.0 本地归档一致；本轮未替换。需检查默认渲染器、Embeddium／Oculus、跨区块、动态段、四朝向、拆解、重登、缺模型回退、脚本及资源刷新；第三方独立世界渲染器不作普遍兼容承诺。
