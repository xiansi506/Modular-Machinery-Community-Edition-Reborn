# 工厂能量信息更新 · 0.115.0

2026-10-26。按所有者“继续”补齐 E9 工厂能量信息。未修改游戏实例或 Git 历史。

## 1.12.2 对照

旧源码 `common/integration/theoneprobe/MMInfoProvider.java:100-126,215-231,306-332` 遍历核心与普通线程，跳过空闲线程，分别累加消耗与生成；取线程 context 的需求、修改器、durationMultiplier 和 parallelism。本版沿用聚合范围，通过现有 Jade server-data 展示。

与旧版取每一侧第一条能量需求、Math.round 的实现不同，本版合计所有能量需求，并使用当前结算的同一 floor／上限规则，避免显示与本版实际扣账不一致。工厂暂停／未成型时不显示；暂时阻塞但持有配方仍计入需求，不能把速率当成实际流量。

## 实现

Jade 能量信息已覆盖工厂核心线程和普通线程，分别合计消耗／生成 FE/t；按各线程并行、冻结的结构／催化剂修改器和当前脚本修改器计算。读取不改变配方执行状态；未成型或红石暂停时不显示，总量累加采用饱和处理。显示的是已持有配方的需求速率，临时阻塞但保留配方的线程仍计入。

新增 `recipe/EnergyUsage`，复用 `EnergyRequirement.perTickDraw` 的显式参数重载，不回写需求的并行或时长倍率；INPUT／OUTPUT 分别饱和相加。工厂快照与 tickThread 共用 effectiveModifiers，保留开工结构／催化剂贡献，替换旧脚本贡献并添加当前控制器／线程脚本。普通机器的 energySnapshot 也复用只读聚合，接口和 Jade 的 energyIn／energyOut 键保持原样；协议仍 5，无新语言键。
