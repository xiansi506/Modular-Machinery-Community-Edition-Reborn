## 实现

- 供应器保存一份共享缓冲及 36 份独立缓冲，按 AEKey 存储 long 数量。原料整批检查、溢出／不支持的 key 整批拒绝；不再直接塞进机器仓口。
- 五模式：默认、合成锁、强化阻挡、普通阻挡、按样板槽隔离。原 0/1/2 模式编号保留，3/4 追加；强化阻挡按缓存是否为空判断，不再错误地等机器完成。
- 新公共接口 `MachineInputProvider` 让供应器与影子方块进入真实结构输入收集；自动隔离组避开普通仓口与其他供应器的组号，保留 selector-tag。两个入口指向同一缓冲时共享事务副本，不能重复扣料。
- 手动辅助输入为两个物品槽和一个流体罐，隔离模式中共用；不参与阻挡、不随退回或模式切换清空。流体容器通过菜单鼠标光标和按钮操作。
- 进入／离开隔离模式会等待旧缓存耗电回网；离线、缺电、容量不足时保留余量并重试。更换有缓存的隔离样板槽，仅退回该槽。等待状态与目标模式均落盘，连续操作以最新目标为准。退回不会取消 ME CPU 的任务。
- 合成锁使用真正包含供应器或其影子方块的机器完成事件解锁，也可手动退回；读取旧锁时保留旧 host。其他模式不依赖完成事件。
- 影子方块 `me_pattern_mirror` 用 AE2 存储卡绑定同维度坐标，不复制内容、不跨维度、不强制加载源区块；加载、卸载、绑定及模式／组变更刷新结构端口。供应器放置时记录 AE 网络所有者；节点状态变化重新广播加工样板。
- 原 36 编码样板槽增加标准物品能力；GUI 保留真实样板交互，新增模式、手动输入、输入组、退回及分页缓存查看。每包最多 32 条缓存预览；完整缓存仅保存在磁盘与掉落内容中。
- 正常掉落携带样板、手动输入、缓存与等待退回状态，排除网络节点。临时缺失附属模组／key 类型时保留无法解析的原始条目，恢复依赖后重读可恢复内容。
- AE2 总线、供应器与影子方块补可选的镐挖掘／石工具标签，避免无 AE2 时标签失败，并使供应器正常采掘掉落可用。镜像模型／贴图／掉落表／创造栏及中英文案已补。
