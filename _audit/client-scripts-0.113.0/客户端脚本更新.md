# 0.113.0 客户端 GUI／模型／动画脚本

日期：2026-10-26。基于工作区 0.112.0，保留此前全部气体、供应器、界面、服务端高级脚本与预览 NBT 改动。Git 基线仍为 `main / 36f34b0`；未提交、推送或部署。

## 实现

- 新增客户端 KubeJS 事件组 `MachineClientEvents.guiRender/modelGet/modelAnimation`，支持全局订阅及机器 ID 过滤。客户端注册表 `MachineClientModels` 持有具名 GeoModelSpec，也可在模型事件中直接指定模型对象。
- 普通／工厂控制器 GUI 均复用现有 ControllerGuiInfoEvent 与文字布局。脚本信息先暂存，回调成功后提交，保留其他附加信息行。
- ClientControllerView 提供客户端已同步状态的只读接口，customData 返回副本，不复用可修改服务器运行时的 MachineControllerAccess。
- 模型／贴图／动画文件每帧共用一次选择结果；未知名字恢复定义默认值。渲染失败会记录并停用该模型，尝试默认模型，脚本／资源重载后重试。
- 动画事件提供序列、循环、播放状态、速度、过渡时间及当前动画／帧信息。过渡时间适配 GeckoLib 4 的整数 tick，速度允许非负有限倍率；无监听器时保留 idle／working 默认行为。
- 修复 WeakHashMap 的弱值可能被普通 GC 回收而随机重置动画的问题：缓存改为稳定值，Animatable 仅弱引用控制器。模型变更重置序列；脚本／资源重载通过 generation 清理动画缓存。
- KubeJS 的 ScriptManager 在每次脚本加载建立一次 bindings。只在 CLIENT bindings 阶段清理并重建客户端具名模型；服务端 bindings 不暴露 MachineClientModels，也不清理客户端注册。
- 实际 KubeJS 6 的 EventHandler 在记录 ERROR 后仍可能返回 PASS。桥接层通过 EventExceptionHandler 显式标记失败，避免接受半写入 GUI／模型／动画结果。错误仍由 KubeJS 正常记录。
- 新增客户端指南与 examples/client-scripts/ 的机器数据包、资源包和脚本。示例纹理复用模组自带外壳 PNG，无额外二进制素材。

## 1.12.2 源码对照

本地 `_mmce-src/ModularMachinery-Community-Edition-master/src/main/java/` 中：

- `github/kasuminova/mmce/common/event/client/ControllerGUIRenderEvent.java`：extraInfo 数组，setter 追加信息；本版相同信息能力接入现有 GUI 排版。
- `ControllerModelGetEvent.java`：通过 modelName 选择模型；本版保留具名选择并允许直接指定整组资源。
- `ControllerModelAnimationEvent.java`：add/setAnimation、循环、过渡时间、playState 0/1、当前动画和帧信息；本版用不引用 GeckoLib 的公共数据事件表示，再由 GeckoLib 4 适配。
- `hellfirepvp/modularmachinery/common/tiles/base/TileMultiblockMachineController.java:1583`：成型状态、动画事件、动画队列与播放状态分发。
- 旧版 DynamicMachineModelRegistry 与 GeoMachineModel 的具名资源机制，映射为 MachineClientModels；资源解析复用现有 GeoModelSpec。

GUI 事件的原有能力是追加文字，不是任意控件画布。本轮没有引入新的服务端包字段、服务器脚本客户端执行，或 CraftTweaker 桥。
