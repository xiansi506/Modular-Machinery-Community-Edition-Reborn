# 0.111.0 高级脚本核心更新

日期：2026-10-26。基于工作区 0.110.0；保留未提交的 0.108.0–0.110.0。Git 基线 main / 36f34b0。本轮未提交、推送或部署。

## 名称与交付

ME机械样板供应器（ME Machinery Pattern Provider）和 ME机械样板镜像（ME Machinery Pattern Mirror Image），方块／物品注册 ID 不变。

已接入：物品／方块检查器、物品改写、结构 NBT 条件、耐久／燃料／延迟触发、机器／配方／升级专属回调、控制器／线程持久数据、具名运行时修改器、工厂核心线程和升级脚本定义。新增公共 script 包不引用 KubeJS/Rhino；桥接类单独位于 kubejs 包。14 类生命周期事件提供全局与专属入口，机器、配方、升级依序分发。

## 旧源码对照与语义

对照本地 `_mmce-src/ModularMachinery-Community-Edition-master/src/main/java/` 下的 RequirementItem、MachineController／IMachineController、RecipeThread／FactoryRecipeThread、事件及升级实现。`legacy-api.json` 收录本次扫描的 63 个含相关注解／接口的文件、277 个方法签名；这不是整个上游 API 总数，也不表示这些签名均已逐一等名移植。

- 输入数量改写在数值修改后、并行放大前执行；仅改数量或恒等改写保留原 Ingredient/NBT 条件，改变物品／NBT 后按返回样板匹配。新增两个不同 NBT 栈合并支付的回归。
- 输出改写接收单件样板，返回数量作倍率；保留随机范围的原始掷点，再进行修改器取整。以 1..4 ×0.5 的逐种子结果验证零产出和原概率分布。
- 耐久按点扣除并处理损坏工具，燃料按燃烧 tick 消耗整件和返还容器；共享事务失败不保留部分支付。
- 延迟需求只在事务成功后标记触发，随在途存档保存；重开工重置。脚本选项使用协议 5 同步。
- 普通／工厂开工检查可阻止支付和限制并行；控制器持久 NBT、进度、状态、具名修改器、升级总线数据和线程配置均接入生产路径。
- 固定核心线程可在普通线程额度为 0 时开工；连续每批触发开始事件。删除工作核心线程保留已付批次，完成后不重开；修改线程配方列表后不重开被排除的配方。核心 ordinal 使用 -2 以下，避免与普通线程／控制器标识冲突。
- 结构 NBT／方块检查器随坐标旋转、合并和动态结构扩展保留；不主动加载区块。
- 重载清理并重绑定闭包与脚本升级声明；运行中的付费配方保留执行副本，必需回调缺失时停止相关结算。
