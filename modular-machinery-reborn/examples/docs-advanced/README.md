# 进阶结构教学包（0.118.3）

把整个 `datapack` 文件夹复制到当前世界的 `datapacks/`，可重命名，确保包根直接包含 `pack.mcmeta`。执行 `/reload`；完整搭建步骤见 [进阶结构示例](../../docs/进阶/进阶结构示例.md)。本包 ID 与入门圆石加工机不同，可以并存。

控制器朝北：西边输入仓、东边输出仓、下方能源输入仓、南边普通箱子。上方放 0～3 层玻璃，最上方必须有一个金块封顶；零层时金块紧贴控制器上方。蓝图命令：`/mm-get_blueprint tutorial:layered_processor`。

配方 `tutorial:layered_stone` 每 100 tick 消耗 1 圆石和 20 FE/t，产出 1 石头。加长玻璃柱只改变合法结构，不增加产量。输入／输出需求使用结构标签 `feed`／`product`。

箱子的 `preview-nbt` 只作用于独立预览实体，不向世界箱子写入名称或钻石，普通箱子也不会变成机器输入端口。离线解析与布局检查不能代替游戏中实际搭建验收。
