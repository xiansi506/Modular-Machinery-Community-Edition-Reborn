# 预览 NBT 示例（0.112.0+）

需要 Minecraft 1.20.1 / Forge。选择一种安装方式：

- 数据包：将 `datapack/` 目录复制到世界的 `datapacks/` 下，命名为 `reborn-preview-nbt`。
- KubeJS：安装 KubeJS 后，将 `kubejs/mm_preview_nbt.js` 复制到实例的 `kubejs/server_scripts/`。

执行 `/reload`，给蓝图选择 `preview_nbt:showcase`，打开蓝图结构预览；也可在 JEI 的结构预览页面查看。

预览包含一个箱子、一面底部带红色横条的白旗帜，以及写有红色发光文字的告示牌。可切层或旋转查看。箱子的名称和内容会读入预览实体，但预览不会打开箱子界面、发放物品或修改实际箱子。

这是机器结构展示，不提供加工配方。`preview-nbt` 仅影响蓝图／JEI 中的显示；需要实际结构具有相应数据时，另外定义 `nbt` 匹配条件。投影仪世界虚影继续使用方块模型。

预览 NBT 的字符串按字面内容读取；普通 JSON 数字／布尔可直接写，指定 NBT 数值类型时用 `"0b"`、`"3s"`、`"1000l"` 等字符串。告示牌文本使用 Minecraft 的 JSON 文本字符串。方块实体字段遵循目标模组的 1.20.1 格式。
