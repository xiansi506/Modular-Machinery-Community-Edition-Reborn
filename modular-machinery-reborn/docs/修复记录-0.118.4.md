# 0.118.4 修复记录 / Fix notes

2026-10-27，Minecraft 1.20.1 / Forge / Java 17，协议 7。

## 修复内容

- **工厂配方重载**：普通线程和核心线程下一批按 ID 查当前配方，并校验机器归属；删除后不再重复开工，同 ID 替换使用新定义。已付料的在途批次保留原执行副本，避免中途替换消耗／产出规则。
- **long 能耗**：未修改整数使用精确 long 路径；修改器保持原 float 聚合规则，再精确计算能源结果。移除四分之一 long 限幅，包含并行与时长补偿的最终结果超界才饱和。缓存不可变修改器实例对应的基础能耗。
- **资源回滚**：逆序尝试所有仓口的恢复，即使某一个抛出 RuntimeException 或 Error；保留操作的原异常，把恢复异常附加到 suppressed。无法强制第三方拒绝恢复的仓口成功，但不让它跳过其他仓口。
- **结构语法**：未知方块 ID 在注册表查找前明确报错，显式 minecraft:air 仍有效。
- **配方查找**：按 RecipeManager 配方表身份缓存各机器的有序不可变列表，支持短机器名、多机器归属与重复别名去重。原版 apply／replaceRecipes 更换表时失效；取不到字段时回退公开 API 扫描。只缓存定义与顺序，每次仍检查当前库存、修改器和输出条件。工厂循环中不随候选重复计算线程规则标记。

## 验证

新增专项 43 项（另含 2000 组随机整数算术对照），既有回归 3338 项，共 3381 项通过、零失败；生产 build/reobf 与资源检查通过。

- 新专项覆盖 JSON 反序列化→long 仓实际收发、2^53 与 long 边界、同 ID 替换／删除、普通／核心线程、异常聚合与 native ItemStackHandler 恢复、原版 RecipeManager.replaceRecipes 缓存失效、真实控制器 FactoryHost，以及库存变化后开工。
- 计数场景：500 条不可开工配方、20 个空闲 tick，定义表扫描从 20 次／10000 条遍历降为 1 次／500 条；资源可用性检查仍执行。这是离线调用计数，不能推算真实 TPS。
- 注册表校验变严后，旧示例测试里未注册的模组仓口不再被空气兜底掩盖；本轮测试副本显式注册真实仓口再解析。旧日志保留，夹具调整与检查明细见同级 _audit/fix-0.118.4。
- 生产包包含 203 个有效 JSON，中英各 424 个匹配语言键，协议 7 与 SRG 检查通过；未捆绑测试夹具和可选模组 API。

## 对照与边界

已对照本地 1.12.2 BlockArray、FactoryRecipeThread、RequirementEnergy。旧版沿用执行副本和 double 能量计算的行为不能满足当前热重载及 long 能量范围；本轮按现有 1.20.1 能力修正。未扩展集成范围。

协议仍为 7。未启动或部署游戏，未暂存、提交或推送本轮修改；实例仍为实查的 0.118.2，真实重载、网络及画面待实机验收。回滚中第三方拒绝恢复的资源仍可能需要日志诊断。缓存依赖 Forge 1.20.1 原版更换配方表的生命周期；字段不可用时退回未缓存路径。

## English

Factory restarts now resolve current recipes, including same-ID replacements and removals, without changing a paid in-flight craft. Long energy arithmetic preserves integer rates beyond 2^53 and removes the quarter-long clamp. Modifier aggregation keeps its existing float semantics; only the final long draw saturates. Rollback attempts every port and preserves the primary exception with suppressed cleanup failures. Unknown block IDs are rejected; explicit air remains supported. Static recipe definitions and ordering are cached per native recipe-table identity, with uncached fallback; resource eligibility remains live.

3381 offline checks passed, including 43 new checks and 2000 additional integer oracle cases. The native recipe-manager, controller host, factory engine, inventory rollback and previous JEI regressions were exercised. No game, OpenGL or real multiplayer/reload acceptance was performed. No deployment, commit or push was performed in this patch.
