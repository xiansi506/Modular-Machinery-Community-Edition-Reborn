# 剩余项清点（0.64.0 基线）

> **用途**：排期与分工。本版是 **2026-10-20 对 `0.64.0` 源码逐项读码**得到的，不是沿用旧表。
>
> **与 [已知限制.md](已知限制.md) 的分工**：
> - `已知限制.md` **§二** = **功能缺口的权威描述**（面向用户：做不到什么、为什么）；
> - **本文** = **状态、依据、顺序**（面向开发）。
> - 两处冲突时，**功能描述以 §二 为准**，并回头改本文；本文新核出、§二 里没有的，要补进 §二。
>
> **取代**：[历史/剩余项清点.md](历史/剩余项清点.md) 的 §2 主表（停在 0.30.1 之前）。那份文件的
> §1「陈旧条目审计」与 §5「有意不做」仍是判定依据，本文不重抄。
>
> **口径（必须照这句读）**：
> 1. 「未做」= **在 0.64.0 里找不到实现**，不是「看起来应该没做」；
> 2. 每条给 `路径:行`，行号对应 `0.64.0` 的源码；
> 3. **本轮没有进游戏**。界面/渲染类条目即便标「未做」，也只是读码结论；
> 4. 「离线可证」指复现器能钉住的部分，**不等于**实机通过。
