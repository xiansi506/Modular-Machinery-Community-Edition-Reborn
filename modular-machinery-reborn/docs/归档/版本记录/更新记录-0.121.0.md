# 0.121.0 可视化配方编辑器（2026-10-28）

可视化配方编辑器首版：机器与配方参数表单、十类资源、JEI 材料拖入、注册 ID 检索、NBT／概率／标签、高级原文保留，以及服务端校验、基础用量预览和 JSON／KubeJS 导出。打开 `/mm-recipe_editor`，需要创造模式与权限等级 2。协议 **12**，两端同时更新；0.120.0 的结构构造工具全部保留。

机器／配方参数、十类现有资源、每 tick／一次性、概率、标签、并行固定成本、物品 NBT 和高级原文均可编辑。服务端原生解析、机器与依赖检查、基础数量预览及启发式端口警告后才能导出。草稿变更、机器被重载移除或旧会话无法复用旧预览写文件。磁盘错误保留草稿；文件写入独立 `exports/recipes/` 且避免覆盖。未增加新的集成范围。

物品 NBT 读入开放既有 literal envelope，保留数组、数值类型和类似数字的文本；传统模板语义不变。KubeJS 导出通过 Java Gson 读取完整 JSON 字符串，保留 long 精度；原生回归同时发现并修复 `MachineRecipeJS.deserialize` 未填必需 MACHINE schema 值而拒绝 `event.custom(...)` 的问题。原文中未表示的高级字段保留，端口与用量提示不能替代运行验证。

## 验证

合计 **3112 项离线检查零失败**（编辑器专项 54、建造增强 33、工具修复 50、主套件 2668、依赖隔离 110 及既有资源／JEI 专项），另有 200 组 JEI 几何场景；Java 17 clean build/reobf 48s 成功，215 个 JSON、中英各 564 个语言键通过检查。

编辑器 54 项执行真实表单补丁与配方／需求解析器，覆盖整数和 long 边界、literal／传统 NBT、资源与逐 tick 组合、高级字段保留、大小／深度限制、草稿票据、重载丢失机器、磁盘失败、权限组合、包往返和 320×240 起的表单几何。生成脚本真实执行 Rhino、JavaWrapper、原生 `RecipesEventJS.custom`、MachineRecipeSchema、`.id()`、序列化和最终配方解析；离线事件派发及 addRecipe 收集使用夹具，平台路径和 Minecraft remapper 使用离线替身，ResourceLocation 使用 KubeJS 自带转换器。该结果证明已覆盖的调用链和精度，不能等同于服务器 `/reload` 实机成功。

依赖隔离 110 项为公共类反射加载，不是完整 Forge 启动。既有 JEI 专项使用捕获绘制命令及几何夹具，未使用真实 OpenGL。最后增加了校验回包与本地 ID／原文／格式的比对：超时后到达的旧回包不能把已修改的草稿标为通过，并重跑 54 项编辑器专项及最终 clean build。主套件和其余集成回归在该次仅涉及回包字段／客户端比对的小修订前运行。

最初三组旧套件因工作目录找不到示例／源文件失败，恢复正确模块目录后全绿；可选 Mekanism 类型保持在 compat 包内。新增脚本回归曾实际复现必填 schema 错误，修复后通过。相关完整日志保留在 `_audit/recipe-editor-0.121.0/`。
