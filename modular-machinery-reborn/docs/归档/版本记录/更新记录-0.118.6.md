# 0.118.6 自然灵气 JEI 绿色条 / JEI Aura gauge

JEI 自然灵气需求改用 gugu-utils 风格的 6×80 绿色竖条，支持输入／输出、从下向上填充、超刻度“＋”及整条悬停提示。

## 显示与语义

- 条形 6×80，预留 100 像素布局高度，10 像素上下留白；两列换行，横向间距 8、纵向间距 4。Aura 与物品／流体／气体／其他魔法格分开计数，输入输出按各自顺序排列。
- 显示满格为 500000 / 3 = 166666；从下向上填充，大于满格显示“＋”。一次性用 amount，逐 tick 用 amount × recipeTime。总量采用精确整数运算，不复制旧版 int 乘法溢出和一次性需求被时长放大的问题。
- 整条悬停保留原需求、灵气类型和脚本说明，逐 tick 附精确总量；说明满格刻度仅用于显示。
- 不依赖空 JEI ingredient 槽位绘制条形，切换到无 Aura 配方不会残留旧条。没有 Aura 的布局与 0.118.5 保持一致。
- 颜色恢复覆盖异常分支。原贴图为 256×257，按真实尺寸采样，避免误用 256×256 默认 UV。

## 来源与许可

改编自 [gugu-utils](https://github.com/ParaParty/gugu-utils) 的 RendererAura.java、JEIComponentAura.java，来源修订 a0724e43d3f73f3de5a5ce1691820741aaa8ea18。recipes_ui.png 以原始字节复制为 gugu_recipes_ui.png，未改动贴图。MIT 版权及完整许可已随 JAR 的 META-INF/licenses/gugu-utils-LICENSE.txt 与 META-INF/NOTICE-gugu-utils.txt 打包，并更新项目 NOTICE.md。无需安装源模组。

## 验证与边界

新增 29 项专项（另含 200 组布局场景），相关既有 2951 项，共 2980 项零失败；生产 build/reobf、203 JSON 和中英各 427 键检查通过。

专项覆盖总量／填充／溢出、捕获的真实 GuiGraphics 调用、完整条形的类别 tooltip、输入输出和不残留绘制，以及 100 组混合布局和 100 组无 Aura 布局与旧实现的对照。场景数是专项内部用例，不再计入检查总数；上一轮专项内 2000 组整数对照也没有重复计数。字体、图形后端和 Minecraft 单例使用离线夹具；未绘制真实 OpenGL。

协议保持 8，配方格式与结算不变，不需要安装 gugu-utils；未启动／部署游戏，画面待实机验收，本轮未暂存／提交／推送。之前 0.118.4／0.118.5 修复均保留，实例仍为实查的 0.118.5，尚未替换。本轮没有增加其他魔法体系或能源后端。

## English

JEI Aura requirements now render a 6×80 green gauge adapted from gugu-utils, with independent layout space, bottom-up fill, overflow marker and full-height tooltips. One-time amounts use amount; per-tick amounts use amount × recipeTime with exact integer totals. Full scale is 166666 raw Aura units for display only. No processing or wire format changes were made; protocol remains 8. Other magic resources keep their existing display.

2980 relevant checks and the production build passed, including 29 new checks with 200 additional layout scenarios. These include captured drawing commands and native category tooltip paths; the game and real OpenGL rendering were not started. MIT attribution and the original texture are packaged; gugu-utils is not a runtime dependency.
