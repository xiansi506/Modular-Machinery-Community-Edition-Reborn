# 0.119.1 建造选择工具修复

日期：2026-10-28。基线 `967accdf`（0.119.0）。当前通信协议 **10**，客户端和服务端同时更新。

修复建造选择工具的 NBT 往返、方块状态旋转、右键交互、跨维度选区、失败后丢失选区、区块漏导出和文件名问题。片段改存 `config/modular_machinery_reborn/exports/`。

## 修复内容

1. 自动导出的 NBT 使用独立字面快照编码，保留原始类型、空容器和特殊字符；已有手写模板的正则／范围规则不变。对无法无损编码的数据中止导出并保留选区。
2. 位置和原生 BlockState 同时归一化为朝北方向，避免楼梯、原木与铁轨等状态错转。
3. 有权限的创造模式工具操作接入物品前置交互；普通右键可选择仓口或从控制器导出，无权限时不阻止正常 GUI。
4. 服务端选区绑定玩家和维度，切维度／重生／退出时清理；同步包携带维度，客户端世界卸载时清理并拒绝在其他维度绘制迟到数据。
5. 完整文件成功写入后才清理选区，IO 失败可以重试；已存在文件使用 CREATE_NEW 保留。
6. 存在未加载／不可读位置时中止整个导出并向玩家报告数量，不再把部分结果提示为成功。
7. 玩家名规整为小写合法文件名，重名添加 `_1` 等后缀；片段存放在独立 exports 目录，避免被自动扫描为不完整机器。

操作：[中文](../../建造选择工具.md)／[English](../../en/Construct-tool.md)。旧片段不会自动移动，完整定义仍由作者补全。
