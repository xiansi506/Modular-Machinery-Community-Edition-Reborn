# 0.120.0 结构构造工具增强

结构构造工具首版增强：逐块／两点框选、选区增减、空气过滤、撤销恢复、材料替换、状态与匹配／预览 NBT 字段筛选，以及完整 JSON／KubeJS／parts 片段导出。协议 **11**，两端同时更新。

本轮合计 **3048 项离线检查零失败**（新增专项 33、此前工具修复 50、主套件 2668、依赖隔离 100 及既有集成专项），另含 200 组 JEI 几何场景；Java 17 clean build/reobf 55s 成功，215 个 JSON、中英各 484 个语言键通过检查。

新增工具面板、HUD、绿色首角点、分页源码预览和确认导出；完整 JSON 与 KubeJS 共享实际解析器验证过的定义。选择操作原子提交，历史、框选体积、选区数量、材料替换和网络内容均有限额。默认不采集匹配或预览 NBT，作者可分别筛选。

导出只写独立 exports 目录；路径由服务端决定。服务端检查创造／权限／持有工具、维度、会话修订号及控制器距离。确认保存时复核世界数据，写入成功才清空选区。旧的七项修复保留，旧工具修复 50 项已回归。可视化配方编辑器仍待实施。
