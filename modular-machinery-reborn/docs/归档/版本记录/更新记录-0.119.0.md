# 0.119.0：气动工艺与余烬联动

日期：2026-10-28。新增气动工艺与指定 Embers Rekindled 复刻版联动，提供 4 种仓口、压力／真空与空气数量需求、逐 tick 结算、余烬小数能量、KubeJS 方法、JEI 资源显示、持久化和共享事务。协议 **9**，两端同时更新。相关离线回归 **2954 项零失败**，另含 200 组 JEI 布局场景；生产 clean build/reobf 通过，本次提交同步 0.119.0 源码、资源、教学包、文档和配方技能；未实机或部署游戏，未创建 GitHub Release。

## 实现

- PneumaticCraft: Repressurized 6.0.23：原生 tier-two 处理器、16000 mL 默认容积、输入／输出仓、压力与真空门槛、一次性与逐 tick 需求；原生邻接与能力、读档、能力失效恢复，输出仓断开连接时漏气。
- 指定的 Embers Rekindled 1.20.1-1.4.7：真实 Ember capability、256000 默认容量、小数输入／输出、模拟传输、存档、逐 tick、并行和修改器。
- 两类资源接入现有端口标签和共享事务；同一缓存不重复记账，失败回滚；空气并行只放大 mL，压力不随并行放大。
- JSON、KubeJS、四种仓口的基础界面／模型／条件掉落、JEI 蓝色／橙色资源格和悬停说明，提供两个完整教学包与等价服务器脚本。
- 容量采用当前项目的通用配置，没有沿用旧版余烬元数据分档和气动升级槽；不提供 Ember 到 FE 的转换或额外第三方配方适配器。

## 验证

新增核心／真实 API／实体／示例专项 48 项、JEI 捕获绘制与混排 10 项；既有魔法核心 52、真实魔法 API 23、同步修复 35、可选依赖隔离 88、JEI 灵气 29、主套件 2669 项，合计 2954 项零失败，另含 200 组 JEI 几何场景。两个数据包、三份配方和两份 KubeJS 脚本另做静态检查；配方技能工具与参考示例也已检查。

新专项通过真实发布 JAR 的 API 和原生空气处理器检查；Forge capability token 在离线测试中使用已有的测试转换代理。主套件保留独立的无 KubeJS 运行环境，更新显式配置数量、语言数量和协议基线；没有删除失败的行为断言。新仓口实体、数据包与 typed 方法也通过实际生产解析器／构建器检查。

未启动或部署游戏。真实管道均压、泄漏／爆炸、接收器／发射器链路、多人联网与 OpenGL 画面尚待实机验收；离线邻接检查不能代替这些验收。
