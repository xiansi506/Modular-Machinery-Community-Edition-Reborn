# 能源、JEI 气体与特殊模型（0.117.0）

本轮功能已实现并完成离线检查、生产构建，尚未进游戏验收。客户端和服务端需要一起升级到协议 **6**，旧协议客户端不能连接。升级前备份世界；新版本保存的大于 int 的能量值不能无损降级给旧版本。

## 配置 long 能量仓

编辑 `config/modular_machinery_reborn-common.toml`。下例将微型能量仓容量设为 100 亿 FE，每次接收／抽取的上限为 50 亿 FE；默认档位数值保持不变。带点的类别名是一个 TOML 键，保留引号。

```toml
["energyhatch.size"]
TINY = 10000000000

["energyhatch.limit"]
TINY = 5000000000

[general]
enable-fluxnetworks-integration = true
```

容量范围为 `1..9223372036854775807`，传输上限为 `1..9223372036854775806`。重启世界并重新加载区块或重新放置仓口，使已有方块实体使用新配置。菜单、比较器、配方资源事务、存档与 Jade 能量仓条均读取完整 long 数值；多个仓口合计超过 long 上限时显示饱和值。

旧存档的 int 能量会完整读入，加载按保存值替换，不受传输上限限制，也不会重复累加。能量输入仓的外部接口只接受能量，输出仓只提供能量；配方仍能分别消耗输入仓、填充输出仓。

## FluxNetworks 与龙之研究

按需安装对应的 **1.20.1** 模组及其依赖。没有这些模组时，普通 FE 功能继续工作。

- **FluxNetworks**：把 Flux Point 连接能量输入仓，把 Flux Plug 连接能量输出仓；提供其 long 能源能力。同名配置开关默认开启，关闭后重启世界以停用该能力。
- **Draconic Evolution**：提供 Brandon's Core 的 OP long 能源能力。可用输入模式的能量水晶或能量塔接收机器输出，输出模式给机器输入仓供能；具体设备方向、绑定和工作条件遵循该模组自己的设置。能量单位按 `1 FE = 1 OP` 交换。

输出仓会优先选择相邻设备的一个 long 接口，每 tick 的六面自动推出共享一个配置预算；同一个设备不会再通过 FE 接口重复收取。相邻设备只有普通 FE 时，每次 API 调用最多 `2147483647` FE。传输限制是每次调用上限，自动推出另有每 tick 合计预算；外部多次抽取不是全局每 tick 限流。

当前接口核对范围：Flux Networks 官方 1.20 分支，以及 Draconic Evolution 1.20 分支所用的 Brandon's Core `1.20.1-3.2.1.302` API。真实网络、设备与多人存读档仍需游戏验证。没有新增 IC2、GT 或其他能源后端。

## JEI 气体罐

气体配方沿用 `mekanism:oxygen` 这样的完整气体 ID，无需改变配方。安装 Mekanism 与 JEI 后，罐格读取气体自身的动画图集贴图及颜色，并显示气体罐壳；悬停保留种类、数量、逐 tick、概率与脚本提示。缺少可用贴图时回退文字。

该显示不依赖 Mekanism 的 JEI 内部 ingredient 类型，因此没有新增气体配方索引／R/U 查询能力。其他化学品也没有随本轮新增。

## 模型骨骼前缀

使用 GeckoLib 模型时，为骨骼名称添加下列前缀，大小写敏感，子骨骼继承父骨骼效果：

| 前缀 | 效果 |
|---|---|
| `emissive`、`bloom` | 全亮，并在世界模型中进入发光遮罩、双向模糊与光晕合成 |
| `transparent` | 透明混合，不写入深度 |
| `emissive_transparent`、`bloom_transparent` | 同时应用全亮、光晕与透明效果 |

透明程度来自贴图 alpha，前缀不会把不透明贴图自动变成半透明。世界光晕按真实深度遮挡，预览保留全亮／透明材质但不执行全屏光晕。每帧最多捕获 64 种发光贴图；额外贴图仍显示全亮。资源重载／断线清理待绘制数据，着色器加载失败会记录日志，并暂停光晕至资源重载，全亮效果继续保留。

光晕采用独立遮罩与场景合成，不要求额外渲染模组。**尚未实测 Embeddium／Oculus、光影包、Fabulous 模式、窗口缩放和资源重载画面**。本轮没有移植异步 VBO 或其他外部模型加载器。
