# 文档索引

> **当前版本 0.119.0，协议 9**：[气动工艺与余烬](气动工艺与余烬.md)已加入，提供仓口、配方和脚本。客户端／服务端同时更新；下方早期修复版本的协议记录属于历史。

当前使用者文档适用于 **Reborn 0.119.0 / Minecraft 1.20.1 / Forge**，协议 **9**。版本修复与验证边界见 [最新交接](交接-2026-10-23.md)，游戏内未验收的内容不视为已通过。

## 推荐阅读顺序

1. 第一次使用：[安装与重载](安装与重载.md) → [入门机器](使用说明.md) → [配方指南](KJS-配方指南.md)。
2. 设计结构：[进阶教学包](进阶结构示例.md) → [结构预览](结构预览.md) → [模型隐藏](世界模型隐藏.md)。
3. 自动化与资源：[ME 自动化](ME自动化指南.md)、[能源与模型](能源与特殊渲染.md)、[魔法资源](魔法资源.md)，按需阅读。
4. 脚本扩展：[高级服务端脚本](高级脚本指南.md)／[客户端脚本](客户端脚本指南.md)；接手开发再读下方维护总纲。
