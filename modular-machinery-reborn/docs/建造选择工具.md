# 建造选择工具

适用于 **Reborn 0.119.1 / Minecraft 1.20.1 / Forge**，协议 **10**。工具负责选区和结构片段导出。

## 操作与保存位置

1. 使用创造模式，并拥有命令权限 2。手持“建造选择工具”，普通右键每个需要收录的方块；再次右键取消该位置。选区在持有工具时显示白色轮廓，显示距离为 32 格。
2. 最后右键机器控制器导出。0.119.1 起工具优先处理点击，选择仓口和导出时无需潜行绕过 GUI。无权限或非创造模式时保留方块正常交互。
3. 文件位于运行服务器的 `config/modular_machinery_reborn/exports/`。单人游戏是本机实例目录；专用服务器需要管理员从服务器取得文件。
4. 文件名采用小写玩家名和时间戳，例如 `machine-kk07h-2026-10-28_16.00.00.json`；重名依次添加 `_1`、`_2`。已有文件不会被覆盖。
5. 只有完整写入成功才清空选区。写入失败、NBT 无法无损序列化或选区存在未加载位置时，保留选区，提示原因后可重试；工具不会为了导出强制加载区块。
6. 切换维度、重生或断线会清理选区。不同玩家的选区相互独立。

当前仍是逐块选择；没有两点框选、撤销或快捷清空。高亮距离不限制选区大小，也不保证远处区块仍然加载。

## 把片段变成机器

导出文件只有 `parts`，不会自动加载。将它复制到一份完整定义，并补上 `registryname`、`localizedname` 等字段：

```json
{
  "registryname": "tutorial:exported_machine",
  "localizedname": "导出的机器",
  "parts": [
    { "x": 1, "y": 0, "z": 0, "elements": ["minecraft:stone"] }
  ]
}
```

保存到数据包的 `data/tutorial/machinery/exported_machine.json`，或配置目录的 `config/modular_machinery_reborn/machinery/exported_machine.json`，然后 `/reload`。新增专属控制器需要配置预声明并重启，见[安装与重载](安装与重载.md)。机器 ID 由 `registryname` 决定；配置文件相对路径也必须符合小写资源路径规则。

导出时坐标和方块状态一起归一化为控制器朝北，楼梯朝向、原木轴向和铁轨形状等按方块自身规则旋转。无需手工再旋转坐标。导出会保留全部方块状态；不想限制的状态属性可以自行移除。

旧版本已经导出到 `machinery/` 的片段不会被自动移动；请自行保存或整理，避免加载器继续把缺少根字段的片段当成机器。

## 导出的 NBT

工具使用带版本标记的字面快照，保留数字类型、空列表、类型数组和字符串原文。例如空箱子的部件可以包含：

```json
{
  "x": 1,
  "y": 0,
  "z": 0,
  "elements": ["minecraft:chest[facing=north,type=single,waterlogged=false]"],
  "nbt": ["mmr:literal_nbt_v1", "{Items:[]}"]
}
```

字符串不会被误当成正则或数字条件；数值类型和数组类型保持不变。这个快照按写出的字段匹配，根复合标签允许实际数据包含额外字段；列表顺序和空列表内容按原值匹配。坐标不进入快照，运行时机箱染色也不会作为结构条件。

**库存、能量、加工进度等仍会成为匹配条件。** 通常应删除不需要的整个 `nbt` 字段，或者改写为只包含必要字段的手写模板。手写模板的正则、比较符及引号规则保持原样，例如 `"nbt": {"Energy": ">=1000"}`。预览显示数据仍可单独写 `preview-nbt`，见[预览 NBT 示例](../examples/preview-nbt/README.md)。
