# 配方结算与供应器修复（0.118.1）

本轮修复已离线复现的四项缺陷，并处理相关性能热点。Minecraft 1.20.1 / Forge，通信协议仍为 **7**。没有新增模组集成，也没有改变原先暂缓的功能范围。

## 延迟需求与配方时长

`trigger-time` 表示原始配方进度中的位置，按**最终整数时长／原始时长**缩放，最后统一取整。100 tick 配方在第 80 tick 触发的需求，缩短到 50 tick 后于进度 40 触发；延长到 150 tick 后于进度 120 触发。

执行进度从 0 开始，触发点限制在 `0..最终时长−1`。一 tick 配方仍执行延迟需求，超出原始时长的触发点放在最后一 tick。脚本跳过触发点时，未执行的需求在后续 tick 补结算；直接完成配方也必须原子结算尚未执行的延迟需求。缺材料或空间不足时不能产出，失败不会写入已触发标记。

`trigger-repeatable` 仍表示再次经过触发点时重触发：已经支付后继续向前推进不会每 tick 重扣。提前完成的补结算只处理尚未触发的需求。

修改后的时长始终在 `1..2147483647` 范围。过大值、正无穷或无法确定的数值饱和为最大时长，非正值保留一 tick 下限，避免 long 转 int 回绕成负数。

这修正了旧源码也存在的提前取整行为，属于有意的缺陷修复。旧脚本若依赖“缩短后跳过扣料”或负数时长，应按正常支付规则调整。

## AE2 缓冲和掉落

真实供应器缓冲在资源归零后移除键，避免长时间处理不同 NBT 时积累历史空槽。事务副本保留本次结算的槽位顺序，提交时再压缩；多个需求连续提取不同资源不会因槽位移位漏料，失败仍恢复原有数量与键顺序。物品／流体槽位列表按键集合版本缓存。

ME 样板供应器、ME 样板镜像、ME 输入总线和 ME 输出总线的掉落表均由内置数据包按 AE2 是否安装生成。未安装 AE2 时不再加载指向未知物品的静态表；已安装时四种方块都能使用对应自身物品的掉落表。供应器原有的 `BlockEntityTag` 内容保留逻辑继续使用。

## 刷新与查询

控制器将匹配结构位置和镜像指向的远端供应器位置登记到依赖索引。供应器加载／移除、模式变更及镜像重新绑定，只标记相关控制器；同一控制器的多次变化合并到其下一 tick 刷新，不强制加载远端区块。卸载、结构变化及重新绑定会更新或移除旧依赖；索引使用弱世界／控制器键。

魔法菜单在每次同步前读取六个完整数值，再拆成 24 个传输分段，同一个 double 不再重复查询四次。能源适配器在初始化时缓存真实 API 的 Method，收发能量时不反复查找方法。

控制器的端口收集已提取为 `ControllerPortCollector`，依赖索引为 `InputDependencyIndex`，配方时间规则为 `RecipeTiming`。这是有针对性的职责拆分；没有重写整个控制器或改动工厂调度架构。

## 验证边界

专项覆盖缩短／加法时长、延迟输入输出、进度跳跃、补结算、重复触发、数值上界、事务槽位稳定、失败回滚、依赖合并和分段读数；完整结果及最终 JAR 以 [交接](交接-2026-10-23.md) §零为准。

没有启动游戏或部署实例，也没有提交／推送。性能改动尚无真实整合包 TPS 基准；不能将减少扫描／查询次数称为已测得的性能提升。真实 Forge 掉落加载、多人、区块重载和魔法／能源设备仍待实机验收。

## English

Delayed requirements now scale against the final rounded duration. Their trigger is clamped to the zero-based execution range. Unpaid triggers catch up after progress jumps and must settle atomically before completion, preventing free outputs. Repeatable triggers only repeat when their point is revisited. Duration conversion saturates safely instead of overflowing to negative ticks.

Provider buffers remove exhausted live keys while transaction shadows retain stable slot positions until commit. Item/fluid key lists are cached. Four optional AE2 self-drop tables are generated only when AE2 is installed, including both ME buses.

A weak dependency index invalidates affected controllers and coalesces repeated refreshes until their next tick. It includes remote provider positions without loading chunks. Magic menu readings are captured once per synchronization, and optional energy API methods are cached at initialization. Port collection and timing rules were extracted into focused classes; the factory scheduler was not rewritten.

Protocol remains 7. Validation is offline; real Forge startup, gameplay, multiplayer and performance benchmarks are pending. No deployment, commit or push was performed in this fix round.
