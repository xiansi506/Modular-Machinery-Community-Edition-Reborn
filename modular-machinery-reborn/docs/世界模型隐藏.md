# 成型后的世界模型隐藏（0.114.0+）

0.117.0 已加入 emissive／bloom／transparent 骨骼前缀；子骨骼继承，全亮、透明和世界光晕的范围见 [能源与特殊渲染](能源与特殊渲染.md)。

机器可以用 GeckoLib 模型替换控制器的方块外观，并在成型后隐藏结构组件。需要客户端安装 GeckoLib，并提供可正常加载的模型资源。

## 设置

在机器 JSON 根对象中添加开关，与 `parts`、`geo-model` 并列：

```json
{
  "hide-components-when-formed": true
}
```

对 KubeJS 机器定义的 builder 调用：

```js
machine.hideComponentsWhenFormed(true)
```

`geo-model` 的模型、贴图和动画路径，以及客户端脚本切换模型的写法见 [客户端脚本指南](客户端脚本指南.md)。[完整示例](../examples/client-scripts/README.md) 提供可复制的数据包、资源包和脚本；示例默认保留输入／输出仓外观，将其机器 JSON 中的开关改为 `true` 即可试验组件隐藏。

## 显示规则

| 机器状态 | 世界中的显示 |
|---|---|
| 未成型、没有可用模型，或没有安装 GeckoLib | 保留原方块外观 |
| 已成型，模型成功渲染，开关为 `false` 或省略 | 隐藏控制器的普通方块模型，保留结构组件和自定义模型 |
| 已成型，模型成功渲染，开关为 `true` | 同时隐藏实际匹配到的组件方块、流体和方块实体外观，保留控制器的自定义模型 |
| 选中模型失败但机器默认模型可用 | 使用默认模型，并按开关隐藏 |
| 所有模型均失败 | 恢复原方块外观；脚本／资源重载后重试模型 |

动态结构使用服务端匹配到的实际长度与朝向。额外修改器的候选方块不自动加入隐藏范围。多个机器共用一个位置时，只要仍有一台有效机器需要隐藏，该位置就保持隐藏；控制器自身的自定义模型保留。

隐藏只改变世界渲染。方块、碰撞、端口、配方、交互和结构匹配继续工作。蓝图／JEI 的预览场景独立，世界隐藏状态不会传播进去。

## 更新与兼容范围

成型后的模型首次成功渲染后，隐藏状态在客户端 tick 更新，并请求重建相关地形区段及相邻面。拆解、模型失效、结构范围变化、区块卸载、脚本／资源重载、断线和切换世界会重新计算或清理。地形重建完成前可能短暂显示旧外观。

已接入 Forge 1.20.1 原版地形、流体、方块实体和邻面剔除路径，以及 Embeddium 0.3.31 的对应地形路径。无需额外安装模型隐藏辅助模组。第三方独立的世界渲染器和着色器画面仍需逐项实机验收。

当前已完成生产逻辑离线检查，以及原版开发命名／生产命名和 Embeddium 实际类的修改检查；没有启动游戏或验收 OpenGL 画面。实机应检查四个朝向、动态扩展、跨区块结构、拆机恢复、重登、资源刷新、缺模型回退，以及原版和 Embeddium／Oculus 下的显示。
