# 使用注意事项与限制

适用 **0.121.0 / Minecraft 1.20.1 / Forge / Java 17**，通信协议 **12**。安装前先看[安装与重载](安装与重载.md)，操作步骤见[教程索引](README.md)。

## 安装与升级

- 客户端和服务端使用相同版本；协议 12 无法连接旧协议服务端。
- 可选联动按需安装，同时满足各模组自身依赖。安装联动模组不会自动生成机器、配方或资源供应。
- 源码已推送不代表二进制已经发布，下载以 GitHub Releases 中的实际文件为准。
- 两项创作工具首版已通过离线回归与正式构建，真实界面、输入／拖拽、资源供给和多人联机仍待实机验收。不要把解析通过当作机器实际加工已验证。

## 机器、配方与控制器

JAR 不内置机器定义或机器加工配方。作者需要通过数据包、配置目录或 KubeJS 提供内容，仓库示例需自行安装。

| 定义来源 | 使用方式与生效时机 |
|---|---|
| 数据包 | 使用通用控制器；完整定义通常可 `/reload` |
| 配置 `config/modular_machinery_reborn/machinery/` | 启动时扫描并预注册专属控制器；新增控制器需要重启 |
| KubeJS 服务端脚本 | 定义机器与配方；新增专属控制器仍需要启动前的预声明和重启 |

数据包或 KubeJS 机器也可通过配置中的控制器预声明获得专属控制器，具体格式见[安装说明](安装与重载.md)。配置机器的来源优先级为 KubeJS > 配置 > 数据包；避免无意覆盖同 ID 定义。普通结构或配方修改按教程重载，新增方块注册不能靠 `/reload` 完成。升级或重载前先备份存档，尽量让在途加工结束。

配方 ID、机器 ID、实际结构、资源仓口和供给都要匹配。JSON 与等价 KubeJS 定义选择一种安装；JSON 的安装路径决定配方 ID。出现问题先检查第一条加载错误，再用 `/mm-syntax` 检查关联、对准控制器 `/mm-diagnose`。

## 创作工具的边界

结构构造工具与配方编辑器都需要创造模式和权限等级 2。导出文件写在**服务端**独立的 `exports/` 目录，不会自动启用定义或执行重载。确认目标命名空间与文件路径后再安装。

- 结构工具最多选择 32768 个位置，撤销／恢复有容量限制；区块不可读或预览后世界发生变化时需重新检查。见[完整操作](建造选择工具.md)。
- 配方编辑器首版最多 64 条需求，JSON 最多 16000 个 Java 字符／24000 个 UTF-8 字节，嵌套深度 64。高级字段用原文编辑，未知字段被保留并不代表引擎会识别它。
- 配方编辑器没有跨会话草稿库和编辑撤销。关闭窗口、跨维度、重生、退出或停服会结束会话；关闭前复制原文留存。
- 预览中的耗量是单份未修改配方的基础值；概率、脚本、修改器、触发时间与并行可能改变结果。端口提示只检查基础结构，不能代替动态结构和实际供应验收。见[编辑器教程](可视化配方编辑器.md)。

## 资源与并行

能源以 **FE/t** 表示，时长以 tick 表示（20 tick = 1 秒）；不要把整次耗能当成每 tick。并行上限只约束配方，不会凭空提高机器的并行能力。NBT 模板、逐 tick 结算、标签和概率有各自语义，按[配方指南](KJS-配方指南.md)填写。

气体需要 Mekanism；魔力、灵气、LP／意志、空气和余烬分别需要对应模组及仓口。气体不包括浆液、灌注物或颜料。魔法与气动资源的实际来源、单位和阈值见[联动教程](README.md#联动教程)。

## 当前功能范围

暂不扩展新的第三方配方适配器；其他魔法体系保留为空；额外能源后端的专门集成范围为 Flux Networks 和 Draconic Evolution。工厂提供独立加工进度，不是真正的异步线程池；智能数据接口以控制器中的数值接口形式提供。

普通玩家与整合包作者按当前教程使用即可。版本排查、旧限制说明和技术取舍保留在[维护归档](归档/README.md)，其中的旧版本行为不能直接套用到当前版本。
