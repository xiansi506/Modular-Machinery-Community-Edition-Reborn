# ME 自动化：总线、机械样板供应器与镜像

适用于 **0.118.6 / Minecraft 1.20.1 / Forge**，协议 **8**。物品和流体需要 AE2；气体额外需要 Mekanism 与 Applied Mekanistics 1.4.3。先让普通仓口上的 [入门机器](使用说明.md) 正常运行，再接入网络。

## 最小加工流程

1. 定义机器结构和加工配方，先验证所需输入、FE/t、耗时和产物。**AE2 加工样板不能替代机器配方**。
2. 将供应器或已绑定镜像写入结构并按图放置，使机器能够读取它提供的输入。不要只把供应器贴在控制器旁边。
3. 供应器接入有频道和电力的网络。在 AE2 中编码与机器配方一致的加工样板，放入供应器；先使用默认模式、单份配方、无催化剂验证。
4. 准备能源输入和产物回网路径。样板把原料送入供应器，**不会替你收走机器的全部输出**；用对应输出仓／ME 输出总线回网。
5. 在 ME 请求一次合成，检查供应器缓冲、机器实际产物及 CPU 任务。确认工作后再添加隔离、镜像、多线程或气体。

ME 输入总线适合维持固定库存；ME机械样板供应器适合接收 ME 请求的加工批次。两者用途不同，可以按配方需要选择。输入总线标记目标量的滚轮、Shift 和 Ctrl 操作见 [目标量滚轮](ME总线滚轮.md)。

## 供应器、模式与镜像

这两个方块的显示名为 **ME机械样板供应器（ME Machinery Pattern Provider）**和 **ME机械样板镜像（ME Machinery Pattern Mirror Image）**。注册 ID 仍为 `modular_machinery_reborn:me_pattern_provider` 与 `modular_machinery_reborn:me_pattern_mirror`，存档中的方块身份不变。下文“供应器”和“镜像”分别指这两个部件。

供应器有 **36 个真实编码样板槽**。在 AE2 样板终端中编码加工样板后放入；仅加工样板参与 ME 合成广播。供应器要接入有电力和频道的 ME 网络，物品管道也可通过物品能力放入／取出编码样板。

供应器先把整批原料存入自己的持久缓冲，机器再从缓冲取料。因此收料不要求机器已经成型，也不受普通输入仓的容量限制。要让机器实际加工，结构定义必须接纳 `modular_machinery_reborn:me_pattern_provider`，供应器必须是匹配结构中的部件；仅仅放在机器旁边不会供料。离线时不接收新任务，但已保存的材料仍可供已加载机器使用。加工产物仍需经输出仓／ME 输出总线回网。

右上角按钮循环切换五种模式：

| 模式 | 行为 |
|---|---|
| 默认 | 不设批次门控，多种样板共用缓冲 |
| 合成锁 | 接收一批后锁住，直到使用该供应器或其镜像的机器发出配方完成事件；中途取消可用退回按钮解除锁 |
| 强化阻挡 | 样板缓冲非空时只接收当前样板；材料被取空后可以接收其他样板，不等待加工完成 |
| 阻挡 | 样板缓冲为空才接收下一批；手动输入不参与阻挡 |
| 隔离输入 | 每个样板槽有独立缓冲和自动分配的输入组，不能把两个样板槽的原料拼成一份配方 |

进入或离开隔离模式会先退回样板缓冲，再完成切换。退回使用 ME 网络电力，网络离线、缺电或存储不足时保留余量并自动重试；等待期间拒绝新批次。更换一个有缓存的隔离样板槽时，只退回该槽的旧原料，避免旧任务与新样板串料。退回原料不会替你取消 ME 合成 CPU 中的任务。

右侧有两个**手动物品槽**和一个手动流体罐。流体容器拿到菜单鼠标光标上后点“流体容器”按钮，可倒入／取出；空容器或填充结果必须有空间存放。手动输入在隔离模式中对所有样板组共用，退回按钮和模式切换都保留它们，适合放辅助原料或催化剂。手动流体不接收气体。非隔离模式的“输入组”可设为 `-1`（通用）或 `0..65535`，点旁边的勾应用；隔离模式的子槽组由系统分配。

“查看缓冲”在样板格区域显示材料名称、数量和样板槽号；星号表示共用缓冲。鼠标滚轮浏览当前页，用右侧 `<` / `>` 翻页。每次同步最多 32 行，实际存储不会因此截断。破坏供应器后的正常掉落携带样板、手动输入、缓冲和等待退回状态，重新放置后恢复。

**镜像** `modular_machinery_reborn:me_pattern_mirror` 可让其他结构读取同一供应器，自己不复制材料，也不提供第二套样板槽：

1. 手持 AE2 存储卡，潜行右击供应器，记录其位置。
2. 在同一维度中，用这张卡普通右击镜像完成绑定。
3. 让结构定义接纳镜像，并将它放在匹配结构的部件位置。

供应器所在区块必须已经加载；镜像不会强制加载远处区块，也不跨维度供料。多个入口在同一次结算中共用同一份资源事务，不能重复计数。普通物品／流体只需 AE2；缓冲中的气体还需 Mekanism 和 Applied Mekanistics 1.4.3。

升级前先完成旧版本正在运行的供应器任务；已有三种模式的存档编号保留，但旧版本已直接送入机器仓口的材料不会自动搬回新缓冲。**通信协议为 8，客户端和服务端必须同时更新。** 以上机制已有离线检查，真实 ME 合成 CPU、频道／电力、界面、区块生命周期、重登及拆放仍需统一实机验收。

## 菜单与缓冲操作

供应器模式按钮支持左键切换下一项、右键切换上一项，并在提示中标出当前模式及等待切换的目标。右下方显示网络在线／离线、合成锁或退回中；退回还需要网络电力与存储空间。

输入组填写 -1（通用）或 0–65535，点击“确定”或按 Enter 应用，Esc 放弃本次编辑，Tab 切换焦点。非法值会变色，确认按钮按状态禁用；提示显示服务端当前值。隔离模式由系统自动分组，输入框不可编辑。

“查看缓冲”每次显示四行，滚轮或拖动右侧滚动条浏览本页，箭头切换服务器返回的页面。名称、图标和数量分列，名称过长会省略；悬停查看来源样板槽、类型及精确数量。k/M/G/T/P/E 是数量缩写，流体和气体的精确数量使用 mB。超大物品数据会使用基础图标，极长自定义文案会截短，实际库存保持完整。

手动流体显示在右侧第三格，悬停可看名称与容量。把流体容器拿到鼠标光标上，按钮会在可操作时启用；服务端以操作栏文字报告转移结果。ME 总线的流体使用原生贴图及颜色，精确数量仍见悬停。


## 气体通道

安装 **AE2 15.x、Mekanism 10.4.x、Applied Mekanistics 1.4.3** 后，现有 ME 输入／输出总线同时提供气体功能，不增加新的气体总线方块。每个总线有独立的 9×8000 mB 气体池，与其流体池分开存储；普通流体仓原有的气液互斥规则继续保留。

- **从网络供气**：把 ME 输入总线纳入结构并连接有频道、供电正常的 ME 网络。在输入总线配置格上，拿装有气体的化学品储罐右键，标记容器内气体；也可使用气体的 AE 编码标记。物品／流体／气体标记在同一格互斥，标记操作不消耗手中物品。总线按目标量从网络补气，超量或清除标记后送回；重复气体标记合并目标，最多维持全池容量 72000 mB。
- **把产气送回网络**：结构中放 ME 输出总线，配方使用 `gas` 或 `gas_pertick` 的输出需求。产出的气体进入其气体池，再送到 ME 网络；网络收不下时保留在总线里。
- **加工样板推气**：用 Applied Mekanistics 支持的气体成分编码加工样板，放入样板供应器。供应器把物品、流体、气体整批存入自身缓冲；遇到不支持的成分或数量溢出时整批拒绝。机器通过供应器或已绑定的镜像读取缓冲。样板目标与机器加工配方仍须匹配，产物通过相应输出端口回网。

气体配置与库存随存档和客户端镜像同步；气体使用自身贴图及颜色，名称与精确数量见悬停。没有 Applied Mekanistics 时气体不会自动进出 ME 网络，气体标记悬停会提示依赖；普通 Mekanism 气体需求无需该附属。本轮未在真实 AE2 网络或游戏界面中验收，先在测试世界验证供气、产气回网、样板混合推料及重登恢复。

## 常见卡住位置

| 现象 | 检查顺序 |
|---|---|
| ME 看不到加工样板 | 是否为加工样板、供应器是否在线、频道与电力是否正常 |
| 缓冲有料但机器不开工 | 供应器／镜像是否属于成型结构，机器配方是否存在，能源、输出、输入组和 selector-tag 是否匹配 |
| 机器已产出但 CPU 一直等待 | 产物是否实际回到 ME 网络，样板的种类、NBT 和数量是否与实际输出一致；先用确定产出排错 |
| 切换模式或退回一直等待 | 网络是否可访问、是否有退回所需电力与存储空间；余量会保留重试 |
| 镜像取不到料 | 是否同维度、存储卡绑定是否正确、源供应器区块是否已加载 |
| 标记了气体却没有补入 | Applied Mekanistics／Mekanism 是否存在，标记类型是否正确，网络中是否有对应气体 |

已有离线行为和布局检查，真实 ME CPU、网络电力／频道、GUI、区块重载、重登及拆放组合仍需实机验收。
