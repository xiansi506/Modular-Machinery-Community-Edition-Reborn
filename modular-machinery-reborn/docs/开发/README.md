## 构建与发布

当前代码为 **0.121.0**，通信协议 **12**。本次仅整理文档目录与导航，不修改模组版本、协议或 JAR。

在项目目录使用 Java 17：

```text
./gradlew clean build --offline --no-daemon
```

`build` 执行 `reobfJar`。默认 Maven 依赖需要先准备缓存；离线依赖包可放入 `libs/` 并设置 `use_local_deps=true`，第三方 JAR 不入库。正式构建和版本归档规则见开发注意事项；二进制通过 GitHub Releases 分发。

历史离线验证入口：[m6c-verify](../../../_audit/m6c-verify/README.md)。这些夹具不等同于 Forge 游戏验收，部分只对应当时版本。各版本的实际验证范围见[版本记录](../归档/README.md)。
