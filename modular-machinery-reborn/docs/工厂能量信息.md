# 工厂能量信息（0.115.0+）

安装 Jade 后，准星指向成型的工厂控制器，可以看到当前配方合计的能量消耗与生成，单位为 FE/t。核心线程和普通线程都参与统计；数值为零的一侧不显示。

例如，一个线程以 2 并行运行 100 FE/t 的配方，另一个以 3 并行运行 40 FE/t 的配方，合计消耗为 **320 FE/t**。如果还有生成 50 FE/t 的线程，会另列“生成 50 FE/t”，两侧分别显示。

## 数值含义

每个线程使用自己的冻结并行数、开工时保存的结构／催化剂修改器，以及当前控制器和线程的脚本修改器。标记为不受并行影响的能量需求按一份计算。时长补偿是否参与速率，遵循现有配置 `general.enable-duration-multiplier`。

这是已持有配方的**需求速率**，不是上一 tick 实际传输了多少能量。缺能量、等待输出空间或事件阻止推进时，仍持有配方的线程继续计入；空闲或配方已被取消的线程不计入。整台工厂未成型或被红石暂停时，不显示能量行。

读取信息不会扣能量、推进配方或修改其执行参数。总量超出 `long` 能表示的范围时显示其上限，避免溢出为负数。

## 显示与验证

服务端计算总量，由 Jade 同步到客户端；普通视图使用千位分组，详细视图显示完整整数。更新时机会受到 Jade 自身刷新间隔影响。普通单配方控制器保留原有能量信息。

本项已通过实际工厂引擎、控制器和 Jade 服务端数据／客户端提示的离线调用检查，未启动游戏。实机应检查多个普通线程、核心线程、并行与修改器、缺能量／输出阻塞、红石暂停恢复，以及存档重载后的显示。
