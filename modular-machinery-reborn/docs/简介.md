# Modular Machinery: Community Edition Reborn

为 Minecraft 1.20.1 / Forge 打造的自定义多方块机械框架，基于 1.12.2 的 Modular Machinery: Community Edition 重新实现。你可以把自己设计的建筑变成加工设备，为它安排物品、流体、能源和气体的输入输出，再用并行、工厂线程和升级系统扩展生产能力。

适合整合包作者、服务器管理者，以及希望自己设计生产流程的玩家。机器结构可由 JSON 数据包、配置文件或 KubeJS 脚本提供，加工配方使用数据包或 KubeJS；模组 JAR 不内置机器定义和机器加工配方，仓库另外提供可选示例。

## 可以做什么

- **设计机器**：任意形状、多层结构、方块状态条件、材料候选、变量集、部件选择标签和重复段动态结构；可使用通用控制器，或预先声明专属机器／工厂控制器。NBT 条件用于配方物品，结构 NBT 匹配仍未实现。
- **编写配方**：物品、流体、逐 tick 能源、Mekanism 气体、备选原料组、数值接口、概率消耗与产出、范围产出，以及提供本次合成增益的可选催化剂。
- **扩展生产**：并行控制器、内置并行、工厂独立配方线程、核心线程、升级总线、结构修改器与部件分组。
- **搭建和查看**：蓝图与 JEI 结构预览、逐层查看、世界幽灵投影、自动搭建，以及把已建结构导出成 JSON 片段的结构构造工具。
- **接入整合包**：KubeJS 机器／配方与生命周期事件；熔炉配方导入与机器间配方复用；可选 AE2 ME 总线、流体总线和加工样板供应器；可选 Jade 信息与 GeckoLib 控制器模型／动画。

机器由服务端加载并同步给客户端。数据修改通常可以 `/reload`；新增专属控制器等方块注册需要重启。KubeJS、JEI、Mekanism、AE2、Jade 和 GeckoLib 都是按所需功能选装，相关依赖请同时满足各模组自己的要求。

## 当前状态

文档对应 **0.107.3，2026-10-25**。项目仍在开发，上述功能已有实现，验证程度各不相同；不能把清单理解为“全部已实机验证”。最近三轮修复已通过完整离线套件 2669 项与专项 29＋22＋18 项检查，构建和出货检查通过；0.107.3 尚未进游戏验收。真实 AE2 网络、多人 LAN、气体管道、自动搭建和视觉表现等仍需实机复验。

这是重新实现，旧版脚本和整合内容需要迁移。旧 CraftTweaker／ZenScript API 不直接运行，第三方配方适配器也未全部移植；GT／IC2 能量集成、MekEng 气体样板等仍未提供。详细范围见 [已知限制](已知限制.md)。
