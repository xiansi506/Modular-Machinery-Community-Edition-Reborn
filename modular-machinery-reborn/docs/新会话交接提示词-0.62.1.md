## 四、这个项目的规矩（**违反了会被指出**）

1. **不许无据推断**：每个判断要有代码位置或实测证据；查不到就写「未查到」。
2. **「看起来合理」不是依据**：原版可观测之处绝不自造「合理的」默认值或行为。
3. **过宽的断言等于没断言**；**假失败与真失败一样有害**；边界要由数据算出来。
4. **「日志里没有报错」不提供信息**——这类缺陷只能用运行时/实机探针 settle。
5. **看不见的状态必须能被问出来**（`/mm-diagnose` 就是为这件事存在的）。
6. **诚实报告未验证的部分**。
