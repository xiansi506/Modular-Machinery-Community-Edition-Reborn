# ME 总线目标量滚轮（0.116.0+）

打开 ME 物品输入总线，将鼠标放在已有的物品、流体或气体配置标记上，即可滚动调节维持数量。输出总线、空白格和下方玩家背包不参与此操作。

| 操作 | 向上滚动 | 向下滚动 |
|---|---|---|
| 普通滚轮 | +1 | −1 |
| Shift＋滚轮 | +10 | −10 |
| Ctrl＋滚轮 | +100 | −100 |
| Shift＋Ctrl＋滚轮 | 翻倍 | 减半，向下取整 |

目标量最低为 1；清空标记继续使用已有的点击操作。物品目标量沿用该物品的堆叠上限，流体／气体目标量沿用共享池容量上限，目前各为 72,000 mB；步进超出范围时夹到边界。

操作只改变配置目标，不消耗手中物品或直接改动内部库存。服务端按当前配置逐次计算，保留物品标记已有的 NBT；连续滚动不会用过时的客户端绝对数量覆盖之前的调整。配置通过既有同步更新，网络延迟下显示可能稍晚。

已通过步进、数量边界、原版菜单消息往返、服务端权限和界面命中检查，尚未实机验收鼠标与键盘操作。
